**-us 	→ agent noun / doer suffix**
ROOT (action or relation) + us → agent noun; one who performs / embodies the root action
Pl**us** 	→ A being	→ the self-being	→ me
Y**us**	→ To rely	→ one who relies	→ follower
K**us**	→ To help	→ one who helps	→ healer

**-y	→ relational / active forms**
ROOT (static noun or basic action) + y → active or causative verb derived from the root
K**y**	→ To care	→ active care → to help
T**y**	→ To destroy 	→ active destruction → to hurt
Plöö**y**	→ God		→ god acting upon the world	→ deity

**-öö	→ higher / abstract / elevated forms**
ROOT + öö → elevated, abstract, or expanded form of the root
Y**öö**	→ To rely	→ expanded rely	→ plural
Plus**öö**	→ Me		→ expanded self	→ we
Pl**öö**	→ A being	→ elevated being	→ god
